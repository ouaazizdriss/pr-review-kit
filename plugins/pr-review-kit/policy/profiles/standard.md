# Profile: standard (`POLICY_PROFILE=standard`)

| Review outcome | Vote |
|---|---|
| Zero points on the code (✅ and ➖ notes only) | **+10** |
| Only 🟡 points on the code | **+5** (approved with suggestions) |
| At least one confirmed 🔴 or 🟠 on the code | **−5** |
| A sibling PR of the same ticket is at −5 | **−5**, with a link to the blocking PR |
| No ticket key (non-Draft) | **−5**, with a reminder |
| Draft PR | **0** (comment only, required reviewer) |

Recommended for a team's first weeks with the kit; move to `strict` once the false-positive rate
is known.
